# 手書き回答の検証項目

新しいMigrationを適用した検証環境で確認する。画像は `storage/app/yuyu-quizzes/handwriting` に非公開保存する。

1. 従来の記述式問題が文字入力のまま表示・保存・採点できる。
2. 手書き問題で線を描き、保存済み表示を確認して画面を再読込する。描画が戻る。
3. 手書きを全消去して保存すると未回答に戻る。中断・再開、提出確認への移動でも最新の画像が保持される。
4. 画像保存中に追加描画しても、古い画像が最終画像を上書きしない。通信エラー時は画面に失敗が表示され、再試行できる。
5. 受験開始後、回答保存前に問題の入力方式を変更しても、その受験には開始時の入力方式が表示される。新しい受験には変更が反映される。
6. 提出後は画像保存・消去が拒否され、採点画面には確定した画像が表示される。採点後に得点と合否が確定する。
7. 別ユーザー、別フレーム、古い画像IDによる画像取得は拒否される。採点権限者のみ、該当フレームで画像を閲覧できる。
8. 画像が1MBを超える場合、PNG以外、期限後の保存は拒否される。

現時点では一問一枚の画像を扱う。画像を再表示した後の「一つ戻す」は、その再表示後の操作にのみ適用する。
