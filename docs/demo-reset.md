# デモ用小テストの初期化

管理者がCLIから使用する任意機能です。通常の小テスト運用では実行不要です。
指定した小テストの受験・回答・採点・手書き画像を保存済みの状態へ戻します。
問題・設定・ユーザー・別の小テストは変更しません。現行yuyu_quiz_*テーブルに対応します。
データのVer.1→Ver.2移行には使用できません。

## 導入
app/Console/Commands/ResetQuizzesDemo.phpをCMSの同じ場所へ配置。
標準Console Kernelによって登録されます。php artisan list で quizzes:reset-demo を確認してください。
DBとファイルをバックアップして、検証サイトで使用してください。

## 初期状態を保存
受験データを用意し、書き込みがない状態で保存してください。

```sh
php artisan down
php artisan quizzes:reset-demo 1 --create-baseline
php artisan up
```

## 復元
復元はメンテナンスモード必須です。実行結果を確認し、最後にサイトを再開してください。

```sh
php artisan down
php artisan quizzes:reset-demo 1
php artisan up
```

ID 1は例です。対象IDを必ず確認してください。確認省略は --force。
--forceでもメンテナンスモードの条件は省略できません。
サイト全体が停止するため、本番での自動実行はこの配布では設定しません。

## 保存・復元条件
- storage/app/quizzes-demo/baselines/quiz-1.json に保存。
- 復元直前に storage/app/quizzes-demo/safety/ へ安全バックアップ。
- 現行形式はformat_version=2。旧ブランチの形式1は受け付けません。初期状態を取り直してください。
- 同一サイト・同一小テスト専用。APP_KEYや設置パスを変更した環境への転用不可。
- 初期状態作成後に問題・ユーザー等を変更した場合は初期状態を取り直してください。
- 手書き画像のバイト列をJSONへ保存。初期状態の画像ファイルが消えていても復元します。
- 既存画像と内容が衝突する場合は中止。既存のファイルを上書き・削除しません。
- DB削除と挿入はトランザクション内で実行。外部キー制約を無効化しません。
- 復元失敗時に新規作成した画像ファイルが残る場合があります。DBはロールバックされます。
- 初期状態と安全バックアップには回答・手書き画像など個人情報が含まれます。公開しないでください。
